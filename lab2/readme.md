# FS (file system) Node
JS's Module

it direct connect with client OS rather than browser

## Major task of FS Module

- Reading and Writing Files
  -> readFile()
  -> writeFile()
  -> appendFile()

- Directory Management
  -> mkdir()
  -> rmdir()
  -> readdir()

- Metadata/ Information
  -> stat()
  -> lstat()
  -> fstat()

- Watching for Changes
  -> watch()
  -> watchFile()
  -> unwatchFile()

- Steaming Large File
  -> createReadStream()
  -> createWriteStream()
  
- File Operations
  -> rename()
  -> truncate()
  -> unlike()
  -> link()
  -> syslink()
